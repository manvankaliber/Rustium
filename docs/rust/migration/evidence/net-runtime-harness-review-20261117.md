**Blocking findings and objections**

1. **The logging proposal changes non-Windows behavior.** [run_all_unittests.cc](/D:/RustiumReview/docs/rust/migration/drafts/net-runtime-harness/integration-proposal/net/test/run_all_unittests.cc:49) applies `LOG_TO_STDERR` on every platform and in every invocation, including child and single-process modes. The frozen [logging settings](/D:/RustiumReview/docs/rust/migration/drafts/net-runtime-harness/source-before/base/logging/logging_settings.h:39) show that POSIX `LOG_DEFAULT` also includes `LOG_TO_SYSTEM_DEBUG_LOG`; the proposal removes that destination before suite initialization. Scope the repair to Windows or preserve the other platforms’ destinations, and establish the intended child/single-process behavior.

   On Windows, the frozen implementation supports the proposed mechanism: initialization before `LaunchUnitTests` selects stderr instead of the default file, and the runner combines stderr with stdout. That should capture subsequent parent diagnostics without opening `debug.log` beside the executable. It does not establish capture of logging before `main`, nor prove suite initialization and command-line logging behavior are unchanged. `InitLogging` also initializes Rust logging and runs before command-line initialization; those interactions need native validation.

2. **The temporary-root containment check relies on a stable filesystem between checking and use.** [native_delivery.py](/D:/RustiumReview/docs/rust/migration/drafts/net-runtime-harness/integration-proposal/.scratch/net-wave5/resumed-integration/native-runtime-delivery-v2/native_delivery.py:515) resolves and checks the parent, then creates it and a child directory without checking the resolved result again. A changed junction or other reparse-point mapping can invalidate the overlap and length checks. Use a controlled, stable parent and verify the created directory’s resolved identity and length before assigning it to the child environment; ensure the approach prevents snapshot mutation if the mapping changes during creation.

   With stable paths, the checks reject the snapshot, its descendants, its ancestors, and parents longer than 48 characters. `mkdtemp` provides a unique directory, and the actual `TMP` and `TEMP` values passed to `Popen` are recorded. The 48-character parent limit is a reserve, not proof that the two native fixtures will fit; that requires the pending native runs.
