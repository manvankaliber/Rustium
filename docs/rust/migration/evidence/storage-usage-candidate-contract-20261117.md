# Director candidate contract for STORAGE-USAGE

This approves internal candidate boundaries and test expectations, not shared exports, ABI, production integration or cutover. Existing `FileSystemUsageCache` and `base::PickleIterator` sources remain authoritative.

- Keep logical keys generic and preserve native FilePath equality/order without normalization or Unicode reinterpretation. The eventual bridge supplies lossless platform keys; no global path service is authorized.
- Preserve constructor `DETACH_FROM_SEQUENCE`: first use may bind a different sequence from construction. The existing native facade checks the single-sequence contract; no independent task/thread service or stronger static restriction is introduced by the candidate.
- Native adapters own actual file/timer resources. Rust owns cache/dirty/validity/update decisions. Model a maximum-two handle cache and its exact policy: every GetFile closes all handles when the size is already two, even when requesting a cached key; then restart the five-second timer before lookup/open. Open uses OPEN_ALWAYS|READ|WRITE; a read of a missing file may create an empty file. Failed opens remove the blank cache entry but retain the scheduled timer behavior.
- `CloseCacheFiles` closes all cached handles and stops the timer. Delete invokes that policy before native deletion or private-map removal. Timer expiry calls the same policy on the bound sequence; destruction closes/stops before releasing the facade. Native callbacks must not retain borrowed Rust input or execute after owner destruction.
- Increment captures `new_handle = !HasCacheFileHandle(key)` BEFORE Read/GetFile. After a successful write, flush only when the old dirty count was zero and that saved flag was true. Flush failure is ignored in the returned write success. Do not replace this rule with unconditional flushing on transition to one.
- Dirty is read as uint32 and increments modulo2^32; rejecting u32::MAX is incompatible. The signed Write parameter transports the same bits back to WriteUInt32. Decrement at zero remains false without a write.
- `PickleIterator::ReadBool` reads the first uint8 then aligns; every nonzero first byte is true, and the remaining alignment bytes are ignored. Rejecting2 or inspecting all32 bits as a canonical bool is incompatible. Native reads request24 bytes at offset0 and may succeed for a longer file; fake providers must not reject extra trailing file bytes merely because the requested buffer is24 bytes.
- Public failures map to false/miss with output parameters unchanged. Use explicit miss/codec/provider error results internally; remove `unreachable!` placeholders on these ordinary paths. A failed write calls Delete, including cache close/timer stop; preserve deletion and flush side effects even when their results are ignored.
- Private instances use isolated memory records and invoke no native file operations; preserve logical existence/deletion semantics and timer/handle separation.
- Signed usage+delta overflow is not given a defined error contract by the original C++ expression. Do not label a new checked rejection as demonstrated parity. Record an explicit provisional wrapping candidate policy and prepare a configured C++ boundary oracle/compiler-flag request before acceptance outside the defined arithmetic domain. No sanitizer campaign is authorized. Ordinary signed boundary behavior remains a validation obligation.

Required candidate work includes fake-provider event traces for open/read/short-read/write/short-write/flush/delete/reopen failures, both handle-cache paths, timer restart/expiry/stop/destruction, first-use sequence binding, all original test cases and malformed records. Real bridge ownership and error translation remain director-owned until independently reviewed and configured-validated.
