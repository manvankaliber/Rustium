156 concrete Rust migration items

Feature-by-feature inventory grounded in this checkout. Numbers are stable reference IDs, not a mandatory execution order. Every item is proposed; implementation status has not been audited.

How independent are these? Bookmarks has its own core build target, //components/bookmarks/browser, but it depends on shared browser services. Its complete feature spans items 001–011 below. We can migrate one item behind its existing interface while callers remain C++.

Scope: This is a first-pass work breakdown, not a claim that 156 tasks cover every shipped target. Infrastructure, engines and Web APIs need further decomposition. Desktop build flags determine which optional features apply. Paths are starting points, not complete ownership boundaries.
